# 🎈 Play Math with Arya

**▶️ Play it here:** https://asifibhuiya.github.io/play-math-with-arya-/

A small, free, ad-free math game for kids. Pop the balloon with the right answer to learn numbers, plus and minus.

## 🌟 The story behind it

My daughter Arya is in class one. She loves playing games on her iPad, and I wanted to show her something special:

> **Games are not only for playing. Anyone can make them, and today AI can help you do it.**

So one day we sat together, I described the game I wanted to an AI coding assistant, and we built it step by step. Arya gave ideas, I tested it with her, and when something did not work we fixed it together. Within a day, her own game was running on her own iPad.

What I wanted her to learn:

- 💡 **An idea can become real.** If you can imagine it, you can try to build it.
- 🤝 **AI is a helper, not magic.** You still need to think, ask clearly, test, and fix.
- 🔁 **Mistakes are part of making things.** The first version did not work, so we found the problem and fixed it.
- 🎮 **You are a maker, not only a player.**

## 🎮 What is in the game

- Numbers 1–10
- Plus up to 10
- Minus up to 10
- Plus up to 20
- Plus and minus mix

Balloons float up with numbers on them. Pop the one with the right answer to earn a star ⭐. Wrong answers just wiggle, with no timers and no losing. The game reads each question aloud.

## 📱 Put it on an iPad or phone

1. Open the game link in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. It opens like an app.

Tip: add `?name=Arya` to the end of the link and the game says hello by name.

## 🛠️ How it is made

- One file: `index.html` (plain HTML, CSS and JavaScript, no libraries)
- Written with the help of an AI coding assistant
- Hosted for free on GitHub Pages
- Written in an older style of JavaScript so it also runs on old iPads
